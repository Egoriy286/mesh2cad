## Эффективный харнесс для mesh2cad
"Сейчас есть 2 основных решения для mesh2cad:
1) Предобученные модели и их комбинация с MLLM как управляющего агента (cadrille, CADENA, CADFather);
2) Frontier MLLM (Opus 5.5, Astra, Kimi K3);

Минус 1) -- страдает генерализация на домены, где модель для кодогенерации не обучали (например, по личному опыту CADFather разваливается на реконструкции сковородки, 
при этом выбивая >98% IoU на деталях в DeepCAD). 
Минус 2) -- сделать качественную генерацию в 1 проход могут только дорогие модели (Opus/Astra) --> получаем большую стоимость за деталь

Цель -- придумать harness для недорогих моделей (Gpt-6 Luna, Qwen), который обеспечит существенное повышение качества генерации в различных доменах 
(детали, предметы интерьера, мебель и т.д.) при существенном снижении стоимости по сравнениб с использованием Frontier моделей. В идеале приблизиться к качеству
 Opus 5.5 с выигрышем по стоимости API (ориентироваться можно на 5x-10х снижение)."
