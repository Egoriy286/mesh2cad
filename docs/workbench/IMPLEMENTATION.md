# Рабочая среда Mesh2CAD — результат реализации

21 октября 2026. Реализация и независимые проверки делегированы агентам
`gpt-6.1-sol` с reasoning `medium`. Существующие незакоммиченные изменения и
исторические эксперименты сохранены. Новых расходов OpenRouter нет.

## Запуск и устройство

```sh
UV_PROJECT_ENVIRONMENT=.venv-mesh2cad uv sync --frozen --extra dev --extra workbench
.venv-mesh2cad/bin/python workbench.py
```

Интерфейс: http://127.0.0.1:8501. API: http://127.0.0.1:8765.
Оба сервиса работают только на loopback; Ctrl-C останавливает их вместе.

- `frontend/`: Streamlit, устойчивый компонент HTML/CSS/JS, локальный Three.js.
- `api/`: FastAPI, SQLite, единая последовательная очередь и worker-поток в
  отдельном от Streamlit процессе. Импорт, CadQuery, evaluation и упрощение
  больших поверхностей выполняются в ограниченных дочерних процессах.
- `.cache/workbench/`: исходники геометрии, нормализация, версии, задачи, диалоги
  и резервирование бюджета. Ключ остаётся только в памяти API.
- Камера сохраняется локально в браузере; черновик каждого asset — в
  sessionStorage вкладки. Ключи в это хранилище не попадают.

Спайк Streamlit прошёл обязательные проверки сохранения сцены, выбора и текста.
Переход на самостоятельный frontend не потребовался. Дизайн использует
наблюдаемые мотивы DeepMind и оригинальные токены приложения, без заявления
об официальной дизайн-системе Google.

## Что работает

Импорт STL/OBJ/PLY/OFF/GLB до 25 MiB, запрет внешних ресурсов и point-only данных,
преобразования экземпляров GLB. Target нормализуется один раз; предсказание не
подгоняется независимо. Вращение, перемещение, масштаб, пресеты, наложение,
видимость, прозрачность и каркас. Метрики IoU, symmetric squared Chamfer,
precision/recall/F-score, H95, ошибки объёма и bounding box, параметры и причины
недоступности. Выбор вручную, по IoU или сопоставимому Chamfer.

Объяснение не исполняется. Правка и ручное редактирование создают дочерние
версии. Поздний результат сохраняет исходный контекст и не переключает выбор.
Переоценка создаёт отдельную версию с параметрами оценки. Экспорт STEP, STL,
Python, PNG, JSON и CSV. Отмена, heartbeat, восстановление очереди, защита от
повторного запроса, транзакционное резервирование затрат.

Офлайн-пример использует детерминированный код, настоящий sandbox и настоящие
метрики; произвольные запросы он не интерпретирует. Для модели предусмотрен
OpenRouter `openai/gpt-6-luna` с ограничением цены и бюджета. Прерванный платный
запрос не повторяется автоматически; неопределённая стоимость остаётся резервом.

В текущую локальную базу повторно исполнены сохранённые программы кронштейна и
блока с карманом из прошлого теста. Это проверка уже полученных результатов,
не новая генерация. Кронштейн: IoU 97.40% → 99.53%. Карман: 70.36% → 63.91%,
несмотря на уменьшение Chamfer. Оба варианта доступны для выбора.

## Проверки и доказательства

- Полный pytest: **103 passed**, 44.14 с. Ruff: без ошибок. После последних
  защитных изменений повторён реальный sandbox workflow и браузерный сценарий.
- **25/25** браузерных проверок: ACK/ошибка, новый текст во время отправки,
  refresh, черновики разных assets, диалоги, пресеты и мобильная компоновка.
- Независимая дизайн-проверка: 1440×900, 1280×800, 768×1024, 390×844; исправлены
  фокус диалогов и подсказка. Повторная проверка: фокус удерживается, Escape
  возвращает его к кнопке; контраст подсказки **6.38:1**.
- Параллельность: 24 запроса не обходят резерв бюджета; 24 запроса с одним
  idempotency key дают одну задачу; 100 гонок отмены завершаются terminal state.
- Свежий UI-сценарий: камера, canvas, выбор и текст сохранены после 4.3 с polling.
  Поздняя правка остаётся дочерней исходной версии при уже переключённом выборе.
- Большая поверхность: 327680 → 29998 граней настоящим VTK decimation в
  ограниченном процессе; оригинал сохранён, поверхность теста замкнута. В
  отдельном viewer harness измерено около 60 FPS за 1.2 с; это локальная проба,
  не гарантия на всех устройствах.

Подробные сценарии, результаты и скриншоты находятся в `.cache/workbench-qa/`:
`frontend-check/`, `design-audit/`, `api-audit/`, `large-preview/`,
`selection-and-persistence.json`, `late-reply-isolation.json`.

## Gauntlet Loop

Эталон: официальный Google AI Studio Build workspace; DeepMind — только стиль.
Два свежих независимых критика просмотрели реальные neutral A/B PNG. Итог
финального overall-сравнения: **invalid, high confidence**. **11/12** обязательных
проверок пройдены; не пройдена сопоставимость внешнего эталона.

У официального PNG неизвестны исходный CSS viewport/DPR и точное состояние
продукта; разная организация проекта влияет на видимость сравниваемых областей.
Живой AI Studio требует входа и в отдельном Chromium, и во встроенном браузере.
Правило используемого skill: “Compare actual artifacts in equivalent formats,
viewports, inputs, and conditions.” Поэтому run имеет статус **blocked**,
а не `won`; победа над AI Studio не заявляется. Нужен доступный сопоставимый
эталон для продолжения именно сравнительного этапа.

Ledger: `.cache/gauntlet/runs/msu-ai-school-b8d9a6c3cd0d/20261021-workbench/`.
Финальный packet/verdict: `.cache/workbench-qa/neutral-final/`.
До и после исправлений сохранены восстанавливаемые source checkpoints.

## Границы первой поставки

STEP импорт, экспорт в исходных единицах, синхронный split-view и облака точек
пока не реализованы. STEP экспортируется в нормализованной системе координат;
обратная матрица сохранена в метаданных. Большое превью приблизительно и не
гарантирует сохранения топологии; evaluation и экспорты используют оригинал.
Codex остаётся в существующем CLI; в UI доступны demo/OpenRouter. Реальный
платный transport в этой итерации не вызывался; его протокол и budget проверены
через mock transport и существующие результаты модели.
