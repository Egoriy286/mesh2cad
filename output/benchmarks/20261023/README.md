# Mesh2CAD: сравнение моделей и harness

Дата эксперимента: 23 октября 2026, Europe/Moscow.

Модели: `openai/gpt-6-luna` и `openai/gpt-6-sol`. Основной метод: classic harness, до пяти генераций. У baseline один вызов генерации, без предварительного анализа.

[Полное описание метода с визуализациями](../../../docs/method.md)

Время включает подготовку входа, вызовы, исполнение, IoU и диагностические рендеры. Задачи выполнялись параллельно, поэтому это время в условиях данного запуска. USD отражает только стоимость API, без цены локальных вычислений.

Ошибки исполнения по лимиту памяти учитываются в результатах. Для одной генерации это неудачный выход; harness может исправить конструкцию по сообщению watchdog. Лимит 2048 МиБ одинаков, оплаченный ответ не запрашивается заново. Счётчики memory_failures сохранены в items.csv и summary.json.

## Ресурсы и интерпретация

Фактически оплаченные завершённые реконструкции: **$1.092123**. Полный журнал новых расходов: **$1.092123**, заданный предел $1.35. Первый ответ дешёвой модели разделяется между baseline и harness, поэтому стоимость этих двух строк не суммируется при расчёте фактического расхода.

План: 50 деталей + 50 объектов. Фактическая когорта - префикс заранее зафиксированного списка с ограничением по ресурсам. Interior300 чередует 4 IndoorCAD и 1 Poly Haven. Во всех условиях внутри домена одни и те же ID и SHA-256. Незавершённые объекты не входят в основную таблицу и перечислены в summary.json. Незапущенные объекты не считаются неудачами.

Незавершённых объектов в журнале: 0.

Дорогая модель с harness является дополнительным условием и не включена в этот запуск: доступный бюджет направлен на три обязательных условия.

Это исследовательская локальная оценка. Список DeepCAD сохраняет исторический порядок выбранных test-объектов, поэтому он не является новым нетронутым holdout. У Interior300 нет официального split, выборка ограничена корректными объёмами. Базовый промпт classic использует формулировку mechanical part в обоих доменах. Этот перенос промпта также может влиять на результат интерьеров. Ни один объект не исключается за низкий полученный IoU.

Одной генерации baseline на объект недостаточно, чтобы оценить вариативность повторных ответов. Дополнительный контроль независимых генераций с тем же числом вызовов нужен для выделения вклада именно обратной связи из общего эффекта дополнительного вычисления.

## Воспроизведение

```sh
.venv/bin/python -m mesh2cad.benchmark --run --limit 50 --budget 1.35
.venv/bin/python -m mesh2cad.benchmark
.venv/bin/python scripts/summarize_benchmark.py
```

Без `--run` оплаченные запросы не выполняются. Завершённые реконструкции повторно не генерируются. Повышение бюджета требует явного изменения budget.json, аргумент CLI не меняет уже сохранённый лимит.
